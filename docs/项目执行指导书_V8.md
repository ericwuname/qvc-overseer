## 二、技术方案

### 需求1: 第50条规则 — `django_sql_injection`

**为什么选这条**：
- Django是Python最流行的Web框架
- SQL注入是OWASP #1安全风险
- `extra()` / `raw()` / `RawSQL` 是Django的常见注入入口
- 这条规则有明确的确定性（CERTIFICATE层），不会增加误报

**实现方案**：
```python
# qvc/rules/python/django_sql_injection.py
# 检测模式:
# 1. Model.objects.raw(f"...{var}...")
# 2. Model.objects.extra(where=[f"...{var}..."])
# 3. RawSQL(f"...{var}...")
# 4. cursor.execute(f"...{var}...")
```

**文件变更**: 新增1个规则文件 + 注册到registry

### 需求2: Python AST级分析引擎

**当前问题**: static_analyzer.py 只用正则匹配，导致：
- 不知道 `app/` 下有 `__init__.py`（import误报根源）
- 分不清函数调用和变量引用
- 无法追踪作用域

**实现方案**:
```python
# qvc/analyzers/ast_analyzer.py (新增)
class ASTAnalyzer:
    def analyze(self, file_path: str) -> ASTContext:
        """解析Python文件的AST，返回语义上下文"""
        tree = ast.parse(source)
        return ASTContext(
            imports=self._resolve_imports(tree),
            functions=self._extract_functions(tree),
            classes=self._extract_classes(tree),
            variable_scopes=self._build_scope_tree(tree),
            call_graph=self._build_call_graph(tree),
        )
```

**与现有流程的集成**:
```
scan_file() 
  → 正则静态分析 (现有，快速初步扫描)
  → AST分析 (新增，提供语义上下文)
  → 规则引擎 (使用AST上下文过滤误报)
  → 置信度引擎
  → 报告
```

**文件变更**: 新增 `qvc/analyzers/ast_analyzer.py`，修改 `static_analyzer.py` 集成调用

### 需求3: GitHub Actions auto-PR

**当前状态**: `.github/workflows/qvc.yml` 只做扫描+报告

**目标**: 扫描发现问题后自动创建修复PR

**实现方案**:
```yaml
# .github/workflows/qvc.yml 增强
jobs:
  scan:
    steps:
      - run: qvc scan . --format json --output qvc-result.json
      - name: Auto-fix PR
        if: failure()
        uses: qvc/create-fix-pr@v1
        with:
          scan-result: qvc-result.json
          auto-fix: true
```

```yaml
# .github/action.yml (新增)
name: 'QVC Auto-Fix PR'
description: 'Scan code with QVC and create fix PR for high-confidence issues'
inputs:
  scan-result:
    description: 'QVC scan result JSON'
  auto-fix:
    description: 'Auto-generate fixes for high-confidence bugs'
    default: 'false'
```

**工作流**:
```
push/PR → QVC scan → 发现问题?
                      ├─ 否 → 通过 ✅
                      └─ 是 → 高置信度(≥90%)?
                              ├─ 是 → 生成修复建议 → 创建Fix PR
                              └─ 否 → 报告警告，不创建PR
```

**注意**: QVC绝不自动修改代码。PR里是"修复建议描述"，不是自动补丁。由开发者/AI Agent根据建议手动修复。
