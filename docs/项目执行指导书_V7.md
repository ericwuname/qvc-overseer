# QVC V7 项目执行指导书

> 代号: "Gene Pool" | 目标: 基因池仓库 + 指纹 50->150 + 社区贡献回路

## 一、V7 目标

| 目标 | 当前状态 | V7 目标 |
|------|---------|---------|
| 指纹数量 | 50 条种子 | 150 条 |
| 基因池仓库 | 无 | qvc-fingerprints 独立仓库 |
| 远程同步 | 本地 only | qvc update 端到端 |
| 社区贡献 | 无 | qvc contribute 自动 PR |
| 指纹质量标注 | 无 | ai_blindspot + verified_projects |

## 二、技术架构

```
qvc-fingerprints/          (独立 GitHub 仓库)
├── verified/              (人工审核过的指纹)
│   ├── python/
│   ├── javascript/
│   └── universal/
├── candidates/            (QVC 自动生成的待审核指纹)
├── stats.json             (每条指纹的统计)
└── README.md

qvc/evolution/
├── syncer.py              (增量同步: 只拉新增/更新的指纹)
├── contributor.py         (自动生成 GitHub PR)
├── gene_pool.py           (本地基因池管理)
├── fingerprint.py         (指纹数据结构)
└── seeds/                 (内置种子指纹, 50->150 条)
```

## 三、实施计划

### Phase 1: 基因池仓库搭建 (0.5 天)
- 创建 ericwuname/qvc-fingerprints 仓库
- 设计指纹 JSON schema (含 ai_blindspot, verified_projects, ai_miss_rate)
- 编写 verified/ 下 50 条种子指纹

### Phase 2: 指纹扩展 50->150 (1 天)
- CWE Top 50 全覆盖
- OWASP Top 10 对应指纹
- Python 专项 20 条
- JS/TS 专项 20 条
- Go 专项 10 条

### Phase 3: 同步引擎增强 (0.5 天)
- syncer.py: 增量同步 (只拉 delta)
- contributor.py: 自动 PR 生成
- CLI: qvc update / qvc contribute 端到端

### Phase 4: 自检 + 文档 (0.5 天)
- 自扫描验证
- 完整项目报告 (中英)
- 用户文档更新

## 四、质量门禁

| 门禁 | 标准 |
|------|------|
| 指纹加载 | 150 条指纹全部可解析 |
| 同步测试 | qvc update 成功拉取远程指纹 |
| 贡献测试 | qvc contribute 生成有效 PR |
| 自扫描 | QVC 扫描自身，高置信度命中率 >= 80% |
| 回归测试 | 所有现有测试通过 |
