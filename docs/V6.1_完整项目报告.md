## 一、项目概述

QVC（QA of Vebe Coding）是一个面向 AI Agent 编程工作流的代码审查工具。它不修改代码，只从 AI Agent 的认知闭环外部审查代码缺陷。

**核心定位**：AI Agent 的外部监工。Agent 说"没问题"，QVC 说"你看这里"。

## 四、架构设计

```
用户 → "scan with qvc"
  ↓
QVC Scanner → 文件发现 + 语言检测
  ↓
StaticAnalyzer → 21 条规则并行分析
  ↓
PostProcessor → 降噪 + 去重 + 严重度归一化
  ↓
BlindspotAnalyzer → 盲区分类 + 漏报率计算
  ↓
┌─────────────────────┬──────────────────────┐
│ qvc-report.md       │ .qvc/tasks/pending.md│
│ （给人看）           │ （给 AI Agent 看）    │
└─────────────────────┴──────────────────────┘
  ↓                       ↓
用户阅读                  AI Agent 读取 → 修复 → 汇报
```
